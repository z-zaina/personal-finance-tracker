# Personal Finance Tracker 

## Description
A simple Python-based CLI application that helps users track income, expenses, and savings. Data is stored locally using JSON for persistent financial tracking.

## Features
- Add income and expenses
- Categorize transactions
- View total balance and summary
- View all transaction history
- Persistent storage using JSON file
